# DDFlow v0.0.1

加强规划阶段的执行准备，减少执行协调者重复推导规则和复核业务内容；完善 ZCode 子 Agent 指派与计划查看体验。

## 主要变化

- Planner 可在用户指定的业务工作区提前准备规则、执行脚本和固定校验器，优先复用可信实现。规划不处理真实业务数据、不试跑业务程序；准备完成和静态检查通过均不代表业务验收通过。
- 建议由较强模型规划，执行协调者只做最小交付与证据核对。确定性检查交固定程序，语义判断交预先规划的复核节点；完整证据保存在约定目录，主 Agent 不默认重复检查。
- 补充任务简报、验收分工、上下文恢复与准备材料交接规则。Re-plan 保留执行历史及其引用材料，修订使用新路径。
- ZCode 使用用户预先配置的真实子 Agent，沿用模型和思考强度设置，不在派发时覆盖。Viewer 显示已有 Agent 信息，隐藏未填写的模型与强度。
- Planner 完成计划后实际检查 CLI，尝试启动或复用只读 Viewer 并打开页面。未安装 CLI 时静默跳过，展示失败不阻塞任务。

## 安装

将项目 README 的安装提示词复制给 AI，或按附件 `INSTALL.md` 操作。已有安装按使用手册重装，并在新会话加载更新后的 Skill。

- `ddflow-skills-0.0.1.tgz`：Planner、Executor 及各自完整协议引用。
- `ddflow-0.0.1.tgz`：CLI 和 Viewer，需要 Node.js 22.13+（22 系列）或 24+。
- `SHA256SUMS`：两个安装包的 SHA-256 校验值。

两个 Skill 仍可脱离 CLI 独立使用。请安装本 Release 的 CLI 包，不安装 npm 上的同名包。现有工作流无需新增字段；需要采用新的任务分工时，先显式 Re-plan 调整 pending Contract，不覆盖 completed / failed 历史。

## 验证与限制

Release 仅在 Linux、Windows 的 Node.js 24 源码验证、测试、分发安装与卸载检查均通过后发布；附件采用 Linux 构建的跨平台 JavaScript 与 Markdown 包。

强模型提前准备与经济协调模型的实际成本收益、执行可靠性尚未实测；ZCode 原生配置与派发、Skill 自动探测及打开 Viewer 的完整宿主流程尚未实测。电商案例仍为教程，业务执行尚未验证。CI 不代表业务结果或 Node.js 22 兼容性已经验收。

代码与文档采用 MIT 许可证；业务数据和处理成果不随软件分发。
