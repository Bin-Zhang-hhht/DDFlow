# DDFlow v0.0.0

首个开源版本：用 Markdown 计划、明确模型分工与产物验收组织长工作流，优先面向多来源数据清洗与整理。

## 本版能力

- Planner 编写任务契约与静态依赖图；用户确认后另行调用 Executor 执行和验收。
- Markdown 保存工作流状态，原始数据只读；失败时停止启动新任务，继续需要显式重新规划。
- CLI 提供 `inspect` 结构检查和 `view` 本机只读可视化。
- 默认安装两个 Skill 和同版本 CLI；Skill 在文档就绪后尝试启动 Viewer，CLI 未安装则跳过。

## 安装

将项目 README 中的安装提示词复制给你的 AI，或按附件 `INSTALL.md` 手动安装。

- `ddflow-skills-0.0.0.tgz`：Planner、Executor 及各自完整协议引用。
- `ddflow-0.0.0.tgz`：CLI 和 Viewer，需要 Node.js 22.13+（22 系列）或 24+。
- `SHA256SUMS`：两个安装包的 SHA-256 校验值。

两个 Skill 可独立于 CLI 使用。请安装本 Release 的 CLI 包，不安装 npm 上的同名包。

## 验证与限制

Release 仅在 Linux、Windows 的 Node.js 24 验证、测试、分发安装与卸载检查均通过后发布；附件采用 Linux 构建的跨平台 JavaScript 与 Markdown 包。

Skill 自动启动与复用 Viewer、ZCode 原生发现与执行尚未完成宿主实测。电商案例为教程，业务执行尚未验证；CI 不代表业务结果或 Node.js 22 兼容性已经验收。

代码与文档采用 MIT 许可证；业务数据和数据处理成果不随软件分发。
